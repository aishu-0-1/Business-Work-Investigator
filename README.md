
# Business Work Investigator

## About the Project
Business Work Investigator is a web-based Business Investigation and Analytics Dashboard developed using Python Flask and SQLite.

## Features
- Add Business Investigations
- View Investigation History
- Edit Investigation Details
- Delete Investigations
- Update Investigation Status
- Dashboard with Analytics
- Generate Investigation Reports
- Print Reports
- Export Data to CSV

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js

## How to Run

1. Clone the repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open your browser:

   http://127.0.0.1:5000
